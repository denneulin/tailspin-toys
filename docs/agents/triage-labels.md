# Labels de tri

Les skills parlent de cinq rôles de tri canoniques. Ce fichier associe chaque rôle au label réellement utilisé dans le gestionnaire de tickets de ce dépôt.

| Label dans mattpocock/skills | Label chez nous   | Signification                                  |
| ---------------------------- | ----------------- | ---------------------------------------------- |
| `needs-triage`               | `needs-triage`    | Le mainteneur doit évaluer ce ticket           |
| `needs-info`                 | `needs-info`      | En attente d'informations de l'auteur          |
| `ready-for-agent`            | `ready-for-agent` | Entièrement spécifié, prêt pour un agent AFK   |
| `ready-for-human`            | `ready-for-human` | Demande une implémentation humaine             |
| `wontfix`                    | `wontfix`         | Ne sera pas traité                             |

Quand un skill cite un rôle (par exemple « appliquer le label prêt pour un agent AFK »), utiliser le label correspondant de ce tableau.

Modifier la colonne de droite pour suivre le vocabulaire réellement utilisé.
